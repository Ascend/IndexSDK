# Multi-Index Batch Retrieval<a name="ZH-CN_TOPIC_0000001456535132"></a>

When the `distances` values are the same, multi-Index batch retrieval uses a different TopK ranking algorithm than single-Index retrieval. Therefore, the labels in the returned TopK results can differ.

<tr><td width="150" align="center" valign="middle">Description</td><td valign="middle">Provides an interface for searching feature vectors across multiple <code>AscendIndex</code> instances. <tr><td width="150" align="center" valign="middle">Output</td><td valign="middle"><code>float *distances</code>: Distance values between the query vectors and the <code>k</code> nearest vectors.<br><code>idx_t *labels</code>: IDs of the <code>k</code> nearest vectors to the queries.</td></tr>

<tr><td width="150" align="center" valign="middle">Constraints</td><td valign="middle">The <code>Index</code> instances participating in search must be created on the same card. The supported <code>indexes</code> types are as follows. <code>indexes</code> may point to <code>AscendIndexSQ</code>, and <code>QuantizerType</code> must be <code>QT_8bit</code>, with 0 &lt; <code>indexes.size()</code> ≤ 10000. <code>indexes</code> may point to <code>AscendIndexIVFSP</code>, and the corresponding <code>QuantizerType</code> must be <code>QT_8bit</code> and <code>MetricType</code> must be <code>METRIC_L2</code>, with 0 &lt; <code>indexes.size()</code> ≤ 10000. The <code>AscendIndexIVFSP</code> indexes participating in search must share the same codebook in shared memory. You can create instances with the shared-codebook constructor provided by <code>AscendIndexIVFSP</code> or through the <code>loadAllData</code> interface. <code>indexes</code> may point to <code>AscendIndexFlat</code>, with 0 &lt; <code>indexes.size()</code> ≤ 10000. <code>n</code> must not exceed 1024. <code>k</code> must not exceed 1024. <code>x</code> must be a non-null pointer, and its length must be <code>dim * n</code>, otherwise out-of-bounds reads or writes may occur and cause the program to crash. <code>distances</code> and <code>labels</code> must be non-null pointers. When <code>merged = true</code>, their length must be <code>k * n</code>, otherwise out-of-bounds reads or writes may occur and cause the program to crash. When <code>merged = false</code>, their length must be <code>indexes.size() * k * n</code>, otherwise out-of-bounds reads or writes may occur and cause the program to crash.</td></tr>
